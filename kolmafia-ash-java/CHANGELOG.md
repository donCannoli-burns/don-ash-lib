# Changelog

## 0.1.0 — 2026-09-27

- Initial Java 21 binding to KoLmafia's Browser JSON API / ASH RuntimeLibrary.
- Blocking and `CompletableFuture` call APIs.
- Typed KoL enum placeholders.
- Property/function batching.
- Pre-transport allow/deny policy hook.
- Dependency-free JSON codec and JDK `HttpClient` transport.
- Java `ashref` wrapper generator.
- Fake-server transport and generator compile tests.
