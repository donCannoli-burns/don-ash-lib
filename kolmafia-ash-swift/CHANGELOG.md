# Changelog

## 0.1.0 - 2026-09-27

- Initial Swift 6.x ASH runtime binding.
- Async/await `AshClient` using Foundation `URLSession`.
- Browser JSON API batching and property lookup.
- Typed KoLmafia enumerated argument wrappers.
- Generic `JSONValue` results and conversion helpers.
- Pre-transport call-policy hooks.
- `ashrefgen` Swift wrapper generator.
- Read-only example.
- Intercepted-transport test suite with no live KoL actions.
